# Força Aliada Manager — distribuição para Windows

Este repositório é o **canal público de instaladores e atualizações** do Força Aliada Manager. Ele não contém o código-fonte do aplicativo.

O Manager é um aplicativo Electron voltado à operação de servidores Minecraft: organização de servidores, console, backups, agendamentos e controle entre computadores. Faz parte da Força Aliada e continua em evolução; consulte a [apresentação e o estágio atual](https://forcaaliada.com/manager) antes de escolher um fluxo de uso.

As versões publicadas podem ser diferentes da versão em desenvolvimento. A disponibilidade de um instalador não significa que todas as funções em evolução estejam liberadas para qualquer conta.
